Place custom external club logos in this folder.

Preferred setup:
- Name the file with the external team id, for example `12345.png`, `fs-team-12345.png`, or `ras-team-12345.png`.
- The app will automatically try the local file first and fall back to the external API logo if the file is missing.

Optional:
- If you need a custom file name, add a manual mapping in `src/lib/utils/teamLogoOverrides.ts`.
