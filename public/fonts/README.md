Place the licensed Dharma Gothic webfont files for exports in this folder.

Supported filenames:
- `dharma-gothic-heavy.woff2`
- `dharma-gothic-expanded-heavy.woff2`
- `dharma-gothic-e-heavy.woff2`
- `dharma-gothic-heavy.woff`

The match editorial export loads these files at runtime and aliases them as
`G22 Dharma Gothic` for the canvas renderer.
